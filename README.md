# Gajender Singh Shekhawat - Personal Portfolio

This repository contains my personal portfolio website, built as part of the Internal Assessment Project.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Cursor AI
- API-based Chatbot Integration
- Vercel (for deployment)

## Features Included
1. **Personalized Details:** Completely updated with my actual educational background (Second-Year student at JECRC University), programming interests, and contact information.
2. **Projects Section:** Showcases the 5 mandatory assignments (Python Collection, Messy Code, Bug Fixing, Quiz, and Reading List).
3. **Interactive Search & Filter:** Instantly filters projects by title or technology.
4. **Dark/Light Mode Toggle:** Allows users to switch UI themes seamlessly.
5. **AI Chatbot:** An integrated API-based chatbot interface ready to answer questions regarding my portfolio.

## Setup Instructions
1. Clone this repository: `git clone https://github.com/yourusername/portfolio.git`
2. Open `index.html` in your preferred browser.
3. For the Chatbot: Add your API endpoint and key in the designated area in `script.js`. **Remember to not expose your secret API key when committing to public repositories.**
